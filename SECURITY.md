# Security policy

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability** (https://github.com/Polivor/polivor-sdk-typescript/security/advisories/new). Do not open a public issue for a security problem.

This package is a client for the Polivor API. It holds no credentials: the API key is supplied by the caller. A report is acknowledged within a few working days.

Only the latest released version receives fixes.
